# МБА-МАИ Manager 360

Профессиональная система управления баскетбольным клубом.

## 🚀 Деплой за 10 минут

### Шаг 1 — Supabase (база данных + авторизация)

1. Идите на [supabase.com](https://supabase.com) → **Start for free**
2. Создайте новый проект: `mba-manager` (придумайте пароль к БД)
3. Подождите ~2 минуты пока проект поднимается
4. **Settings → API** — скопируйте:
   - `Project URL` → это ваш `NEXT_PUBLIC_SUPABASE_URL`
   - `anon / public key` → это ваш `NEXT_PUBLIC_SUPABASE_ANON_KEY`
5. **SQL Editor → New Query** — вставьте содержимое файла `supabase/schema.sql` → **Run**
   - Это создаст все таблицы и загрузит реальный состав МБА-МАИ

### Шаг 2 — Vercel (хостинг)

1. Идите на [vercel.com](https://vercel.com) → **Sign up with GitHub**
2. **Add New Project** → **Import** репозитория (или перетащите папку)
3. В **Environment Variables** добавьте:
   ```
   NEXT_PUBLIC_SUPABASE_URL    = https://xxxxx.supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY = eyJhbGc...
   ```
4. **Deploy** → через 2 минуты ваш URL вида `mba-manager.vercel.app`

### Шаг 3 — Первый вход (создание администратора)

1. В Supabase → **Authentication → Users → Invite user**
2. Введите ваш email → **Send invite**
3. Проверьте почту, кликните ссылку, придумайте пароль
4. Теперь зайдите на ваш сайт → войдите
5. Вы войдёте с ролью **player** — нужно повысить до admin:
   - В Supabase → **Table Editor → profiles**
   - Найдите вашу запись → поле `role` измените на `admin`
6. Обновите страницу — вы администратор 🎉

### Шаг 4 — Добавление пользователей

В разделе **Управление** приложения:
- **Invite user** через Supabase Authentication
- Назначьте роль в панели управления
- Для игроков — привяжите к карточке игрока

## 🔧 Локальная разработка

```bash
# Установите зависимости
npm install

# Скопируйте переменные окружения
cp .env.local.example .env.local
# Заполните SUPABASE_URL и SUPABASE_ANON_KEY

# Запустите
npm run dev
# → http://localhost:3000
```

## ✨ Функционал

- **Состав** — полный CRUD игроков, статусы, статистика
- **Нагрузка** — тепловая карта RPE за 7 дней по всем игрокам
- **RPE** — игроки вносят нагрузку самостоятельно (замена Яндекс Формы)
- **Медицина** — журнал травм и восстановления
- **Аналитика** — статистика + сезонный RPE
- **Управление** — назначение ролей пользователям
